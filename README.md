# 🧮 Calculator

A simple, easy-to-use calculator that performs everyday arithmetic operations.

## ✨ Features

- Addition, subtraction, multiplication and division
- Decimal number support
- Clear (C) and delete/backspace functions
- Handles invalid input and division by zero
- Clean and simple interface

```bash
# Replace with the command for your project, e.g.:
```

## 📖 Usage

1. Launch the calculator.
2. Enter the first number.
3. Choose an operator (`+`, `-`, `×`, `÷`).
4. Enter the second number.
5. Press `=` to see the result.
6. Press `C` to clear and start again.

**Example:**

```
12 + 8 = 20
15 ÷ 3 = 5
```
